Hello everyone, this README is being written to ease everyone into the user interface of the rubics cue solver.
It will be in two parts, the input (how you input data into the interface) and the output.

<h2>Input</h2>
First order of business is to put the cube with the white dot in the middle facing upwards and colour the all white side with the colours on your cube.
Go around the faces of the cube making sure that you follow the faces precisely as wrong inputs could result in the wrong solution for your cube or an error.
